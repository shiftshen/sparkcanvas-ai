# LibTV 模块对比与 SparkCanvas 提升计划

## 产品原则

- 画布只展示可扫读摘要，大段内容放到底部编辑器或全屏展开。
- 节点所有操作固定在选中态底部面板，避免右侧面板遮挡或看不全。
- 品牌是 SparkCanvas 的差异点：所有生成节点都能用 `@LOGO`、`@IP`、`@产品`、`@模特` 等引用品牌图片与文字上下文。
- 空素材不进入引用候选，避免用户误以为已经有图。

## 对比结果

| 模块 | LibTV 优点 | SparkCanvas 已实现 | 下一步 |
| --- | --- | --- | --- |
| 画布 | 暗色网格、节点连线、左下缩放和整理 | 已有网格、动态连线、整理、小地图、吸附、缩放 | 小地图可点击定位 |
| 节点 | 节点展示摘要，点击后底部编辑 | 已把品牌/提示词改为 `@` 标签摘要 | 补批量选择和批量移动 |
| 添加节点 | 节点后 `+` 支持继续扩展 | 已支持图片、文本、视频、脚本、合成、音频 | 节点模板化推荐 |
| 图片生成 | 进度清晰、失败有提示 | 已接本地 skill，生成后替换当前节点，显示进度/状态 | 增加取消任务和失败重试原因详情 |
| 文本/故事版 | 表格字段完整，可转分镜 | 已有故事版卡片和表格模式 | 增加表格全屏编辑 |
| 素材引用 | `@` 引用素材 | 已支持 `@品牌/@LOGO/@IP/@产品/@模特`，图片自动进 refs | 增加键盘上下选择和搜索过滤 |
| 素材库 | 我的素材入口清晰 | 已有上传、编辑、删除、多选加入画布 | 增加素材预览详情和版本来源 |
| 品牌管理 | LibTV 无品牌管理 | SparkCanvas 已有品牌字段、图片素材、自动注入 | 品牌资产分组和完整性评分 |
| 历史版本 | 节点有重新生成/历史入口 | 已有历史选择和从素材替换 | 节点级版本时间线 |
| 视频/合成 | 视频参数和合成入口 | 已有视频和合成配置节点 | 接真实视频模型后补输出资产 |

## 本轮已落实

- 品牌上下文从大段文本改为 `@` 引用格式。
- 画布上的品牌/提示词节点改成标签摘要卡片，避免全文挤满画布。
- `@` 候选同时包含品牌文字字段和真实图片素材；有图片的素材会写入节点 `refs`。
- 后端最终提示词同步使用 `@` 引用格式，并提示模型解析带 `[image]` 的参考图。
