# SparkCanvas AI 部署方案与开发计划

## 1. 部署架构设计 (基于 xmanx.com 现有基础设施)

鉴于目标是部署在现有的 `marketing.xmanx.com` 站点，我们建议采用基于 Docker 容器化的微服务部署方案，以确保新旧系统的平滑过渡和高可用性。

### 1.1 基础设施需求
- **计算资源**：至少 2 台高配云服务器（如 AWS EC2 或阿里云 ECS），建议配置 8核 16G 内存。
- **GPU 资源**：如果选择自建底层 AI 模型（如部署 ComfyUI），则需要额外的 GPU 实例（如 NVIDIA A100/A10）。初期建议直接调用第三方 API 以降低成本。
- **存储**：AWS S3 或阿里云 OSS，用于存储海量图片和视频。
- **数据库**：托管版 PostgreSQL (如 Amazon RDS) 和托管版 Redis (如 Amazon ElastiCache)。

### 1.2 容器化与编排 (Docker & Kubernetes)
- 所有微服务（前端、API 网关、NestJS 后端、Worker 进程）均打包为 Docker 镜像。
- 使用 Kubernetes (K8s) 或 Docker Swarm 进行容器编排，实现服务的自动扩缩容和故障恢复。

### 1.3 域名与路由配置
- **主域名**：`marketing.xmanx.com`
- **前端静态资源**：通过 Nginx 代理，配置 CDN 加速，直接响应用户的页面请求。
- **API 网关**：配置在 `api.xmanx.com`，使用 Nginx 或 Kong 进行反向代理，将请求路由至后端的不同微服务。

## 2. 持续集成与持续部署 (CI/CD)

为了保证开发效率和代码质量，必须建立完善的 CI/CD 流程：
1. **代码托管**：使用 GitHub 或 GitLab。
2. **自动化测试**：每次提交代码触发 GitHub Actions，运行单元测试和前端 E2E 测试。
3. **自动构建镜像**：测试通过后，自动构建 Docker 镜像并推送到私有镜像仓库（如阿里云 ACR）。
4. **自动化部署**：使用 ArgoCD 或 Jenkins，将新版本的镜像自动部署到测试环境或生产环境。

## 3. 分阶段开发计划

为了控制风险并快速验证市场，项目开发分为三个主要阶段（MVP、核心功能、完整版），预计总周期为 3 个月。

### 阶段一：MVP（最小可行性产品）- 预计耗时 4 周
**目标**：跑通核心的“无限画布 + 一句话出图”流程。
- **第 1-2 周**：
  - 完成系统架构搭建、数据库设计和 CI/CD 流程配置。
  - 前端：集成 tldraw 引擎，实现基础的无限画布交互（平移、缩放、创建区块）。
  - 后端：搭建 NestJS 基础框架，实现用户注册、登录和积分系统基础。
- **第 3-4 周**：
  - 后端：实现 Intent Router（意图解析），对接 OpenAI API 解析自然语言指令。
  - AI 层：对接第三方图像生成 API（如 Stable Diffusion 接口），跑通“一句话生成单张图片”流程。
  - 前端：完成魔法输入框与画布区块状态（生成中/成功/失败）的联动。

### 阶段二：核心功能（Brand Agent 注入）- 预计耗时 4 周
**目标**：实现系统的核心差异化壁垒——智能品牌资产注入。
- **第 5-6 周**：
  - 后端：开发 Brand Agent 模块，集成 Milvus 向量数据库。
  - AI 层：对接 Vision LLM，实现对用户上传 Logo 和参考图的特征提取与向量化存储。
- **第 7-8 周**：
  - 后端：实现 RAG 检索逻辑，将品牌特征自动注入到生成 Prompt 中。
  - 前端：开发左侧悬浮面板（资产库与模板库），支持模板拖拽到画布。
  - 联调测试：确保用户只需输入“生成海报”，系统能自动贴上其 Logo 并保持风格一致。

### 阶段三：完整版与优化部署 - 预计耗时 4 周
**目标**：支持多模态（视频）、完善国际化，并正式部署上线。
- **第 9-10 周**：
  - AI 层：接入视频生成大模型 API（如 Kling），支持在画布上生成视频。
  - 前端：全面实施 i18n 国际化方案，支持中/英/泰切换及 RTL 布局适配。
- **第 11-12 周**：
  - 性能优化：优化无限画布在加载大量高清图片时的内存占用，优化接口响应速度。
  - 部署上线：在 `marketing.xmanx.com` 基础设施上进行预发布环境测试，最终灰度发布至生产环境。
