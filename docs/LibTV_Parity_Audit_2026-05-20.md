# LibTV 画布对齐审计 2026-05-20

## 参考站点观察

- 顶部保留项目名、保存、分享、会员和积分入口。
- 左侧主工具极简：添加节点、工具箱、我的素材、历史记录、教程、客服。
- 选中节点后进入元素选择模式：中上方浮层显示当前模式、返回节点、退出；非目标区域会弱化。
- 节点后方提供动态加号，可继续添加文本、图片、视频、脚本、合成等节点，允许一对多扩展。
- 画布左下固定整理画布、小地图、连线/吸附、缩放比例控制。
- 底部编辑器固定位置，不跟随画布缩放；图片、文本、视频各自保持固定尺寸和固定参数区。
- 文本故事版使用可横向浏览的多字段分镜结构，适合后续接视频节点。

## SparkCanvas 当前对齐结果

- 左侧导航已改为 LibTV 风格命名，并保留 SparkCanvas 的品牌管理入口。
- 节点选中时新增元素选择模式浮层，可返回节点或退出；点击画布空白处会退出编辑/选择。
- 非选中节点在选择模式下弱化，当前节点高亮，便于聚焦操作。
- 连线保留一对多关系，节点后的加号继续添加图片、文本、视频、脚本、视频合成、音频。
- 新增连线拖动手柄，可上下微调当前连线落点。
- 新增左下角整理画布、小地图、网格吸附、缩放、适配控制。
- 文本节点支持故事版卡片渲染，后端生成故事版表结构仍使用本项目模型链路。

## 保留差异

- 图片生成和模型配置不接 LibTV：继续由后端调用 `scripts/generate_image.py`，默认 `cliproxyapi · gpt-5.4`。
- SparkCanvas 增加品牌上下文和品牌素材自动注入，这是本项目核心差异。
- 视频、音频、合成节点当前先保存完整配置和流程位置，真实视频生成后续按模型接入逐个实现。

## 后续优先级

1. 将历史记录从项目级升级为节点版本级，支持每个图片节点独立回滚。
2. 将多选/区域选择完善为批量移动、批量删除、批量加入合成。
3. 将小地图从静态概览升级为可点击定位。
4. 接入真实视频模型后，让视频节点输出真实视频资产。
