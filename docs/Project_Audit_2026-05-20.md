# SparkCanvas 项目审计与推进记录

审计时间：2026-05-20 00:52 ICT

## 目标判断

项目目标不是普通图片生成 demo，而是面向 `xmanx.com` 的品牌驱动 AI 工作流画布：

- 一个项目对应一个可编辑画布。
- 品牌档案、Logo、IP、产品、模特、店铺视觉等素材自动参与提示词和参考图。
- 画布节点支持图片、文本、脚本、视频、视频合成、音频、输出与参考资源。
- 节点可点击、可编辑、可继续向后追加节点，并支持一对多分支。
- 图片生成由后端调用本地 `scripts/generate_image.py` skill，默认模型 `cliproxyapi · gpt-5.4`，不在前端直接请求图片 API。
- 模型与参数必须可切换、可保存、可测试，不写死在 UI。

## 未完成与风险

- 真实图片生成已通过本地私有 `auth.json` 和本地网关验证。生产部署仍必须通过环境变量或私有配置提供密钥，不能提交密钥。
- 当前 `/ai/diagnostics` 显示 `keySource=auth.json` 且 `canAttemptGeneration=true`。真实生成依赖本地网关 `http://192.168.1.83:8317/v1` 可访问。
- 文本、脚本、视频当前是规则化生成/配置保存，还未接入真实文本 Agent 或视频生成 skill。
- 浏览器自动化环境缺少虚拟剪贴板，中文输入类交互无法通过 Playwright `fill/type` 稳定断言；后端 smoke test 已覆盖对应 API。
- 当前项目目录不是 git 仓库，回滚只能通过手工反向补丁、备份或重新解压项目包完成。
- 画布交互仍是自研实现，接近 RunningHub/Liblib 的交互框架，但不是完整像素级复刻。
