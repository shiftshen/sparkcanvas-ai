# ui-ux-pro-max 目标（目标模式）

## 一句话目标
把系统从“可点页面”变成“可解释 AI 作业台”：所有输入在底部，所有节点可追溯，所有关键动作能被单步、批量、回放处理，默认以 Pi Skill 作为底层执行单元。

## 目标边界（第一阶段）
1. 登录后 **30 秒内** 完成一条目标闭环：`输入目标 → 自动生成 6~8 个节点 → 绑定模型和素材 → 运行 1 个节点 → 看到预览/结果摘要`。  
2. 左侧对象库可拖拽导入素材到画布；右侧可修改节点参数并持久化；底部输入框统一接收目标与操作指令。  
3. 节点失败时，用户可见“错误文本 + 推荐动作 + 一键修复”并可立刻执行 `只重跑该节点`。  
4. 所有输出卡必须显示：模型、参数、输入素材、提示词来源、耗时和可复用动作（重生、标记、下载）。  
5. 禁止阻塞主线：任何失败不得卡死画布或全局按钮，应有 fallback 与可跳过路径。

## 页面骨架（固定布局）
- **顶栏**：项目名 / 当前目标摘要 / 系统状态 / 顶部快照按钮（刷新/重排/回放/导出）。  
- **左栏 250px**：对象库（目标、素材、品牌、技能、模型、流程、结果、反馈）；默认展示 3 列切换卡片；支持本地搜索和收藏。  
- **中栏**：ReactFlow 主画布，节点最小宽度 280，默认 24px 边距，网格吸附 + 节点状态色（灰/蓝/绿/红）。  
- **右栏 340px**：节点工作台（总览/模块/执行痕迹三 Tab）+ 节点参数编辑。  
- **底栏 212px 固定高**：目标输入区 + 执行区，固定在页面底部，不得覆盖中栏和右栏内容。  
- **右侧抽屉**（Skill 管理）：`activeNode` 与本地 Skill 只在右侧抽屉展示，不再在画布中塞满内容。

## 画布交互规则（必须统一）
- 节点支持点击选中、拖拽、连接、删除、克隆、上插/后插/分支插入、重命名。  
- 选中节点后，顶部弹出工具栏固定显示：`运行 / 重试 / 模型 / Skill / 日志 / 素材 / 保存技能 / 打开 Skill 文件`。  
- 画布仅显示“节点摘要 + 关键状态 + 3~4 个核心动作”；其余参数默认收起到右栏模块页。  
- 节点状态含：`就绪 / 运行中 / 成功 / 失败 / 队列中 / 跳过`。

## 节点与按钮规范（逐页可核）
- **通用按钮（所有节点）**：选中、运行、重试、停用/启用、复制、删除、打开 Skill。  
- **路径按钮（结果节点）**：再次生成、导出、切换成素材。  
- **执行恢复**：只重跑失败、只重放失败、全流程重放、清空失败标记。  
- **流程控制**：启动、停止、暂停、跳到下一节点、跳到上游、跳到下游。  
- 每次动作写一条 `runId` 到日志，节点卡显示最近一次 `耗时/错误码`。

## Skill 体系规则
- Skill 分层：内置基础 Skill（文本 / 图片 / 视频 / 素材检索）+ 用户本地 Skill。  
- 进入“模块”标签后可进行：参数 JSON、示例输入、执行预览、diff、版本回滚。  
- Skill 运行必须写回：输入摘要、返回码、模型名、token、执行时长、是否触发 fallback。  
- 支持 `pi search` 与 `pi create` 两类入口；`pi build` 输出仅更新技能草稿，不直接写入仓库主干。

## 底部目标输入与命令系统
- 底部输入框只读输入目标；左侧给 3 个快捷模板（TikTok、短视频、品牌主图文）。  
- 回车默认触发 `生成流程`；`Ctrl/Cmd + Enter` 触发 `运行当前节点`。  
- 输入框始终显示 `系统建议指令`（例如“先补素材后生成”, “先调模型再重试”）。  

## 追踪与反馈
- 右侧“执行痕迹”必须按时间轴显示：Input Source、Skill Trace、Model Trace、Asset Trace、Output Trace。  
- 结果预览按 `nodeId` 与 `resultId` 双索引检索，支持查看缩略、打开原图/原视频、复制链接。  
- 反馈标签写入记忆与模型策略后，左上角系统徽标显示“今日学习条目数/命中率”。

## 验收（可执行清单）
- 5 分钟内完成一次目标创建并成功触发至少 1 次节点运行。  
- 新手首次操作 85% 步骤在不看文档下可独立完成。  
- 节点按钮触达率（运行/重试/回放）≥ 95%。  
- 结果缺失率（预览、模型、素材、日志）≤ 3%。  
- 连续 3 次失败，系统能提供可执行建议而非“无响应”。

## 低风险迭代顺序（只做第一阶段）
1) 左/中/右/底四区稳定布局落地（当前优先）。  
2) 节点动作优先级（运行、重试、重排、回放）从中栏剥离到顶部工具栏。  
3) 右栏模块页承载参数、Brand、Model、Skill、Asset 四大折叠模块。  
4) Skill 抽屉改为“编辑中心”，不影响画布空间。  
5) 结果追踪与反馈通道打通，输出摘要可见后再接入历史与回放。

> 约束：不改造基础模型链路，不新增不可回滚的持久化，所有 UI 提案先落文档后分期开发。
