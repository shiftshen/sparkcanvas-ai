# SparkCanvas AI 验收清单

## 1. 本地启动

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

演示账号：

- 账号：`shift`
- 密码：`123456`

## 2. 核心功能验收

- 登录后直接进入无限画布工作台。
- 未登录时不能直接加载工作区，必须先进入演示账号。
- 当前默认品牌为 XMANX。
- 顶部魔法输入框可以创建生成任务。
- 顶部可以选择模型，例如 Seedream 4.0、FLUX Kontext、SDXL Product Pro、Kling Video。
- 画布任务区块必须显示输入图节点、提示词节点、模型节点、输出图节点。
- 画布任务区块必须显示节点之间的连线。
- 生成任务会显示进度，完成后状态为 `已完成 / 100%`。
- 积分会按任务成本扣减。
- 生成结果会自动写入资产库。
- 左侧模板库可一键创建模板任务。
- 左侧品牌面板可切换品牌、编辑品牌名、Logo 文本、颜色、语气和市场定位。
- 左侧资产面板可新增素材。
- 左侧历史面板可定位历史画布区块。
- 画布支持拖动平移和滚轮缩放。
- 画布区块支持拖拽移动，位置会保存到后端。
- 右侧检查器展示 Intent Router 和 Brand Agent 的内部步骤。
- 右侧检查器展示当前任务使用的模型和完整提示词。
- Brand Agent 步骤中应显示注入 XMANX。
- 导出按钮可导出选中任务 JSON。
- 中、英、泰语言可切换。

## 3. 自动化验证

```bash
npm test
```

该命令会执行：

- TypeScript 类型检查。
- 前后端生产构建。
- 后端冒烟测试。

冒烟测试覆盖：

- 健康检查。
- 登录。
- 工作区加载。
- 品牌创建与激活。
- 资产创建。
- 一句话生成。
- 异步任务完成。
- 积分扣减。
- 生成资产入库。
- 画布区块位置保存。
- 工作区导出。

## 4. 生产域名

生产域名按单域名架构：

- Web：`https://xmanx.com`
- API：`https://xmanx.com/api`

这样可以减少跨域、Cookie、证书和代理复杂度。

## 5. 当前边界

当前版本是可运行的产品 MVP，AI 生成由后端模拟适配层完成。真实模型接入时优先替换 `POST /generate` 后面的任务执行器，前端画布、品牌上下文、资产库、积分扣减和任务状态无需重做。
