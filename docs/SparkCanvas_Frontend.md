# SparkCanvas AI 前端技术方案

## 1. 前端架构概览

前端应用基于 React 18 和 TypeScript 构建，采用 Vite 作为构建工具，以提供极速的开发体验。核心的画布功能基于 `tldraw` 引擎实现，状态管理采用轻量级的 `Zustand`。

### 1.1 核心依赖
- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **路由**：React Router v6
- **状态管理**：Zustand
- **画布引擎**：tldraw (`@tldraw/tldraw`)
- **UI 组件库**：Tailwind CSS + Radix UI (或 shadcn/ui)
- **网络请求**：Axios + React Query
- **国际化**：i18next + react-i18next

## 2. 组件结构设计

应用采用扁平化的组件结构，最大化画布的可视区域。

### 2.1 顶层布局 (`AppLayout`)
- 负责整体的页面布局，包含顶部的控制栏、左侧的悬浮面板和中央的全屏画布。
- 处理全局的键盘快捷键和拖拽事件。

### 2.2 顶部控制栏 (`TopBar`)
- **魔法输入框 (`MagicInput`)**：处理自然语言输入，支持拖拽文件。
- **品牌切换器 (`BrandSelector`)**：下拉菜单，用于切换当前激活的品牌档案。
- **状态指示器 (`StatusIndicator`)**：显示当前的积分余额和系统状态。

### 2.3 左侧悬浮面板 (`LeftPanel`)
采用可折叠设计，包含三个主要标签页：
- **资产库 (`AssetLibrary`)**：展示用户的历史图片、上传的 Logo 和模特。
- **模板库 (`TemplateGallery`)**：按行业分类展示可拖拽的生成模板。
- **工具箱 (`QuickTools`)**：提供抠图、扩图等单点工具的快捷入口。

### 2.4 智能画布 (`SmartCanvas`)
基于 `tldraw` 封装的核心组件。
- **区块管理 (`FrameManager`)**：管理画布上的不同项目区块。
- **自定义形状 (`CustomShapes`)**：扩展 tldraw 的形状，增加“生成中占位符”、“AI 生成结果框”等自定义组件。
- **画布事件处理 (`CanvasEventHandler`)**：处理拖拽、缩放、双击等交互事件。

## 3. 画布实现细节

### 3.1 tldraw 集成
使用 `<Tldraw />` 组件作为画布的基础。通过配置 `components` 属性来自定义画布的 UI（如隐藏默认的工具栏，替换为我们自己的极简 UI）。

### 3.2 自定义 AI 生成节点
在 tldraw 中注册自定义的 `shape`，用于表示 AI 生成任务。
- **状态**：包含 `pending`（排队中）、`generating`（生成中，显示进度条或骨架屏）、`success`（显示结果图片/视频）、`error`（显示重试按钮）。
- **交互**：选中该形状时，弹出悬浮菜单（Floating Toolbar），提供“重新生成”、“变体”、“下载”等操作。

### 3.3 历史项目区块化
不再使用传统的列表页管理项目。每次新的生成任务（无论是通过魔法框还是拖拽模板），系统都会在画布上的空白区域自动创建一个新的 `Frame` 形状，并将生成的图片放置在其中。用户可以通过平移画布来浏览历史项目。

## 4. 状态管理策略

使用 Zustand 进行全局状态管理，按功能模块划分 Store：

- **`useAuthStore`**：管理用户登录状态、Token 和基本信息。
- **`useBrandStore`**：管理当前激活的品牌档案信息（Logo URL、品牌描述等）。
- **`useCanvasStore`**：管理画布的视口位置、缩放比例和选中的元素 ID。
- **`useTaskStore`**：管理当前正在进行的 AI 生成任务的进度和状态。

## 5. 国际化 (i18n) 方案

- **基础配置**：使用 `react-i18next` 进行文本翻译。初始化时加载中、英、泰三种语言包。
- **动态切换**：在顶部控制栏提供语言切换按钮，切换时实时更新界面文本。
- **RTL 支持**：针对可能需要从右向左阅读的语言，通过在 `<html>` 标签上动态切换 `dir="rtl"` 属性，并结合 Tailwind CSS 的逻辑属性（如 `ms-4` 代替 `ml-4`）来实现布局的自动镜像。
