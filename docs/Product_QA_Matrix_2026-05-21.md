# SparkCanvas 产品级 QA 矩阵

日期：2026-05-21

## 结论

之前的“测试团队”偏技术检查：接口、构建、局部按钮是否存在。这个口径不能证明产品专业，也不能证明用户可以完成工作。上线前必须改成产品目标驱动的 QA：每个角色都围绕同一个闭环验收，而不是分散找小 bug。

SparkCanvas 的产品目标不是复刻一个普通画布，而是让品牌资产能被 CAL 语言像代码变量一样引用，并自动生成可控工作流。任何测试、设计和开发都必须服务这个目标。

## 角色分工

### 产品负责人

验收问题：用户能否从“一个品牌需求”走到“可下载交付物”。

必须通过：

- 新建项目可以绑定品牌，也可以无品牌。
- 新建项目默认空画布。
- 一句话输入能生成工作流，而不是只生成单张图。
- 工作流每一步都可编辑、重跑、替换素材。
- 输出结果能回到画布和素材库。

### UX 设计

验收问题：用户是否知道自己在哪、素材如何引用、结果在哪里。

必须通过：

- 品牌素材必须显示 `$` 标签。
- Assets 必须按品牌组织，不能混在一起。
- 画布左侧导航不能跟随画布缩放和平移。
- 底部编辑器必须稳定显示，不被右侧浮层遮挡。
- 生成按钮、运行工作流、下载、重生成、保存版本必须可见。
- 补全列表可滚动、可点击，不秒退。

### 前端工程

验收问题：交互状态是否可靠保存。

必须通过：

- 节点拖动和连线调整保存后刷新不回退。
- 品牌切换不误切当前画布。
- 图片上传后立即显示缩略图。
- 图库选择不是空操作。
- 选择 JPG/PNG/PDF/MP4 后，只显示相关参数。
- 移动端和窄屏下弹层不被裁切。

### 后端工程

验收问题：数据、文件和任务状态是否真实可靠。

必须通过：

- 上传图片落盘，workspace 只保存 URL。
- `/workspace` 重新加载后品牌资产和画布引用仍存在。
- PDF 输出是真实 PDF。
- MP4 输出没有文件时不能标记完整成功。
- AI 状态接口不暴露密钥。
- 生产禁用公开 demo 认证或必须显式开启。

### AI 工作流

验收问题：CAL 是否真的驱动模型和 skill，而不是只改提示词文案。

必须通过：

- `@imgen` 默认调用本地图片生成 skill。
- `$logo`、`$ip`、`$menu.buffet` 等图片变量进入 `imageReferences`。
- `$copy.slogan` 等文本变量展开到最终 prompt。
- `$dapot` 可引用整个品牌上下文。
- `$dapot.ip` 只引用该资源。
- 失败时返回缺失资源、模型不可用或 skill 配置问题。

### QA

验收问题：是否能用固定脚本和页面路径复现结果。

必须通过：

- `npm test` 通过。
- 发布前，或改动登录/认证、CORS、公开引用 URL、上传/对象存储、视频生成生产链路后，必须单独运行 `npm run test:production-smoke`。
- 浏览器完成一次品牌上传、CAL 补全、生成工作流、重跑、下载。
- 至少一个 DAPOT 真实品牌素材路径跑通。
- 至少一个 PDF 输出下载验证。
- MP4 未获得真实文件时必须展示处理中或失败状态。

## 当前 P0

1. 生产认证和文件鉴权仍需上线前加固。
2. MP4 真实文件交付仍需严格区分“任务已创建”和“文件已产出”。
3. 国际化覆盖还不完整，工作台仍有硬编码中文。
4. 产品教程需要从符号说明升级为完整教学路径。

## 当前 P1

1. 品牌生命周期需要补删除、归档、导入导出和保存失败提示。
2. 输出中心需要统一展示 JPG/PNG/PDF/MP4 的状态、下载、重试和版本。
3. IP 一致性需要资产层规则，例如 `$ip.main`、`$ip.style_ref`、禁用错误 IP。
4. 模型探测和高成本生成需要权限、配额、速率限制。

## 近期执行顺序

1. 先修“用户看得见”的闭环：品牌素材上传显示、标签可编辑、图库选择、画布节点重跑。
2. 再修“真实生成”的闭环：`@imgen` 图片、PDF 真文件、MP4 任务状态。
3. 再修“上线安全”的闭环：生产认证、文件鉴权、CORS、错误脱敏。
4. 最后打磨“国际化和官网教材”：中英泰教程、示例代码、可复制案例。

## 放行标准

不以“功能存在”为放行标准，只以“用户能完成任务”为标准。

最小放行任务：

```text
@imgen /生成海报 使用 $dapot.logo $dapot.ip $dapot.menu.buffet，为 DAPOT 自助火锅生成泰中文 5.1 活动投放海报 %premium -> JPG
```

验收结果：

- 画布出现完整工作流。
- 参考节点显示 DAPOT logo、IP、菜单素材。
- 输出节点显示生成图片。
- 图片可预览、下载、保存到 DAPOT 素材库。
- 保存后的素材显示新的 `$` 标签。
- 刷新页面后项目、节点、素材仍存在。
